# Security & Sensitive Issue Reporting (Invite-only)

If you discover a security vulnerability or a sensitive issue, DO NOT file it as a public issue.

## How to report (private/secure)

- Email: security@threecreative.nl (PGP key available on request)
- Include: detailed reproduction steps, logs, and affected build identifiers
- Mark the email subject: [SECURITY] Saviour vulnerability

We will respond within our stated SLA to invited testers and coordinate any triage privately.

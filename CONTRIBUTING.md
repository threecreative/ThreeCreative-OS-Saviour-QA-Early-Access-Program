# Contributing — Invite-only QA Review

This repo is restricted to invited QA reviewers.

## How to contribute

- Run test cases in TEST_PLAN.md.
- File issues using templates under .github/ISSUE_TEMPLATE.
- Include logs and clear reproduction steps.
- Respect confidentiality — do not distribute builds or artifacts.

## Issue triage

- Label issues with severity.
- Include platform details and exact steps.
- Link related issues if they appear connected.

## Code of conduct

- Be professional and respectful. Feedback should be technical and actionable.

## Contact for access

- testing@threecreative.nl (request access if you have been invited but lack repo permissions).

# ThreeCreative OS Saviour — QA Review (Invite-only)

This repository is the invite-only QA review workspace for ThreeCreative OS Saviour (early-access desktop environment built on ThreeCreative‑DOS Curiosity).

Important: access to this repository and its builds is restricted to approved QA reviewers and internal engineering staff. This repository is not public-facing and is not intended for open signups or general participation.

## Purpose

- Coordinate structured QA reviews by invited testers
- Provide test plans, templates, and instructions for review sessions
- Collect reproducible issues, logs, and structured feedback from reviewers

## Access and invitations

- Only invited QA reviewers may access this repository and its artifacts.
- If you're reading this and believe you should have access, contact testing@threecreative.nl. Do not attempt to share builds or repository contents with non-invited parties.

## Contents

- TEST_PLAN.md — test cases and checklists for reviewers
- REVIEW_GUIDELINES.md — expectations and quality criteria for review work
- .github/ISSUE_TEMPLATE/* — templates for bug reports and feedback
- SECURITY.md — private security reporting and contact
- NOTICE_INVITE_ONLY.md — short pinned notice for contributors

## How to run a review

1. Confirm you are an invited reviewer and have access to the private build artifacts.
2. Read REVIEW_GUIDELINES.md and TEST_PLAN.md.
3. Execute test cases, record results, collect logs/screenshots.
4. File issues using the provided templates and include attachments and reproduction steps.
5. Tag issues with severity and whether the issue is blocking further testing.

## Communication channels

- Primary (private): testing@threecreative.nl
- For internal coordination: private Slack/Matrix channel (invite only)
- For emergency/security issues: follow instructions in SECURITY.md

## Confidentiality

- Builds, logs, and discussion in this repository are confidential to the invited QA group and the ThreeCreative engineering team.
- Do not share artifacts, screenshots, or logs outside the invited team without explicit permission.

Thank you for helping make Saviour more reliable and polished.
